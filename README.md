# ezpark
Sering bingung berapa total biaya parkir setelah ditinggal seharian di mall? EZPark hadir sebagai aplikasi Smart Parking Management System yang memproses perhitungan tarif dasar hingga promo diskon otomatis secara real-time. Dibuat dengan antarmuka interaktif yang bersih dan cepat, menjadikan pengalaman parkir lebih efisien dan terprediksi.
